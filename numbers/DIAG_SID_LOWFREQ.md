# SID 저주파 오차의 공간 구조 — 전역 통계가 가린 것

- 대상: SID test split 전량 598장 / 50씬 (표본 아님)
- 모델: Retinexformer 저자 SID.pth, repro_sid_retinexformer.py 와 동일 규약
- 방사 주파수 구간·로더·8bit 규약은 diag_sid_spectrum.py 에서 그대로 import 했다(같은 11구간)
- 별도 표기가 없으면 장별 오라클 전역이득 a=<p,g>/<p,p> 를 곱한 출력(클리핑 없음) 기준
- 채점은 repro_measure.psnr_indep 만 사용. 전부 실측값.

## 2. 저주파 오차의 공간 구조 (f < 0.10, 최저 2 대역)

출력(전역이득 보정)과 GT 를 이상적 저역통과한 뒤의 차이맵 D = LP(p) - LP(g) (휘도, 0-255).
블록 통계는 64x64 화소 블록 기준이다.

D 에너지몫에 두 열이 있는 이유: 장별 비율의 평균(장평균)과 에너지 가중 합계(E가중)가 다르다.
앞선 문서들의 대역 오차몫은 에너지 가중 쪽이고, 이 차이 자체가 저주파 오차가 장마다
크게 갈린다는 신호다(소수의 장이 저주파 오차를 크게 낸다).

'장상수 몫' = 장 전체 평균값 하나가 D 의 에너지에서 설명하는 비율. 이게 작으면
전역 통계(장 하나에 스칼라 하나)로는 D 를 못 잡는다는 뜻이다.

## 3. 국소 보정 오라클 — 해상도 사다리

블록마다 최소제곱 스칼라를 골라 GT 에 맞춘다. 계수는 채널 공통이다(전역이득 오라클과 같은 단위).
  gain : a_blk * y          (요청받은 이득맵. 전역 1x1 은 정의상 전역이득 오라클과 같다 = 0번 앵커)
  off  : p + b_blk          (전역이득 보정 출력에 국소 오프셋만. 저주파 오차는 가법이라 이쪽이 직결이다)
  aff  : a_blk * y + b_blk  (블록마다 2 자유도)
대조군은 자유도 효과만 재려고 목표를 GT 대신 가짜로 바꾼 것이다. 같은 절차·같은 블록수다:
  white : 목표 = p - (같은 분산 백색잡음)     -> 구조 없는 잔차. 이게 '자유도 대조군'이고 이 값을 뺀다.
  perm  : 목표 = p - (같은 노출 다른 장의 잔차, 채널별 분산 정합)
          -> 잔차의 공간 구조(저주파 우세)는 그대로 두고 이 장의 내용과의 정합만 깬 것.
             빼지 않는다. '이 장에 특유한 몫인가, 저주파 잔차면 아무거나 되는 몫인가' 를 가르는 참고선이다.
PSNR(u8) 은 클리핑+8bit 반올림 후 psnr_indep, PSNR(float) 은 클리핑 없는 최소제곱 잔차 기준이다.
이득 차이는 대조군을 뺄 수 있게 float 열에서 계산한다(둘의 차이는 0.01 dB 수준).

## 측정이 가리키는 것

- 모순은 없다. 최저대역이 오차의 54.73% 를 갖는 것과 대역 재가중이 0.73 dB 뿐인 것은 같은 사실의 양면이다. 데이터셋 전역 대역이득은 그 대역 오차를 0.36% 밖에 못 없앤다(전 대역 합쳐 0.031 dB). 그 대역의 rho 가 1 에 가깝다는 건 최적 이득이 이미 1 이라 재가중으로 손댈 게 없다는 뜻이지, 오차가 작다는 뜻이 아니다. 대역LS 의 +0.7~0.8 dB 도 대역 구조가 아니라 장별·채널별 자유도에서 나온다.
- 그 대역 오차는 공간적으로 변한다. 최저 두 대역만 남긴 오차맵 D 는 전체 오차 에너지의 64.4%(RGB) 인데, 장 전체 상수 하나가 설명하는 몫은 8.8% 뿐이다. std/평균|D| 가 1.28, 64x64 블록 평균의 사분위 범위가 -3.07~2.33 계조다. 전역 통계는 이걸 못 본다.
- 무작위도 아니다. 블록 평균의 자기상관이 이웃 블록에서 수평 0.683 / 수직 0.557, 부호 일치가 0.801 / 0.758 다(무작위면 0 과 0.5). 한쪽은 계속 어둡고 다른 쪽은 계속 밝다.
- 크기: 국소 이득맵 오라클로 25.779 -> 26.966 dB(16화소 블록, 자유도 대조군 보정 후 +1.194 dB), 국소 affine 이면 +1.819 dB 다. 자유도 대조군(white)은 0.006 dB 로 무시할 수준이니 이 이득은 자유도가 아니다. 노출이 짧을수록 커진다(0.1s +1.17 -> 0.033s +1.49 dB, affine 은 +1.80 -> +2.00).
- 다만 이 성분은 이 장의 내용에 붙어 있지 않다. 같은 노출 다른 장의 잔차를 갖다 붙인 대조군도 1.185 dB 로 실측 1.199 dB 와 거의 같고, 블록 오라클 이득의 국소 변동을 관측 가능한 블록 통계(입력 평균휘도·입력 분산·출력 평균휘도)로 예측한 교차적합 R2 는 0.0061 로 0 이다(GT 블록 평균을 넣으면 0.6927). 판정은 국소판 '회복 가능' 이 아니라 '이 특징으로는 미식별' 이다 - 성분은 크고 실재하지만, 블록 단위 밝기·분산 통계는 그게 어디서 얼마나 틀리는지를 담고 있지 않다.

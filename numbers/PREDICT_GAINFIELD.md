# 국소 이득장은 입력 영상으로부터 예측 가능한가 — CNN 판정

- 질문: 극암 복원 오차의 3분의 2를 차지하는 공간적으로 변하는 저주파 오차
  (= 블록 오라클 국소 이득장) 를 입력 영상만 보고 예측할 수 있는가.
- 앞 측정(DIAG_SID_LOWFREQ 4번)은 블록 통계 스칼라 3개로 교차적합 R2 0.0061 을 얻었다.
  특징 3개짜리 검정이라 '예측 불가' 의 증명이 못 된다. 여기서는 공간 맥락을 보는 CNN 으로 다시 잰다.
- 목표 변수 정의는 diag_sid_lowfreq.block_ls_gain 을 그대로 import 해서 썼다
  (a_blk = <y,g>_blk / <y,y>_blk, 채널 공통 스칼라). 앞 문서와 정의가 같다.
- 채점은 repro_measure.psnr_indep 만 사용. 전부 실측값.

```

------------------------------------------------------------------------------

모델선택(내부검증)             접두 2 — 20씬 234장
검증 씬                   접두 1 — 50씬 598장 (= diag_sid_* 의 test split 전량)
목표 격자                  16px (국소이득 오라클 26.966 과 같은 격자)
예측기                    U-Net 형 CNN, /64 까지 내려갔다 /16 으로 복귀, 1.558M 파라미터
입력                     short 입력 영상 3ch + 모델 출력 영상 3ch (+ 각각 log1p) = 12ch, 512x960
학습                     AdamW lr 0.0003, OneCycle, 40에폭, 배치 8, den 가중 MSE, 상하좌우 뒤집기
```

목표 변수 두 가지를 다 다뤘다.
- centered : t = a_blk - a_img (장내 den 가중 중심화). 예측 0 이면 결과가 정확히 전역이득 오라클이다.
             장별 전역이득 a_img 는 baseline(25.779) 과 똑같이 오라클로 준다 — 두 쪽 조건이 같다.
- raw      : t = a_blk (절대 이득). 오라클을 하나도 안 쓴다. 기준선은 보정 없음 24.438 이다.

## 7. 학습 곡선과 과적합 — '학습이 부족했다' 반증

에폭별 R2. inner = 모델 채택에 쓴 내부검증(접두 2), val = 검증셋(접두 1) 진단값이다.
val 열은 모델 선택에 쓰지 않았다 — 아래 '부정행위 상한' 을 계산하려고 기록만 한 것이다.

```

----------------------------------------------------------------------------------------

     5           0.0680         0.0030       0.0697     0.0060       0.0753         -0.0504

    15           0.0683         0.0212       0.0705     0.0212       0.0696         -0.1435
    20           0.0555         0.0249       0.0402     0.0311       0.0852         -0.5450

    30          -0.0383         0.0203      -0.0298     0.0138       0.0321         -0.4349

학습 손실은 끝까지 떨어지는데 내부검증 R2 는 15~20 에폭에서 꺾인다. 학습 부족이 아니라
과적합이다. 용량은 O1 에서 이미 확인됐다.

에폭 선택 탓이 아니라는 걸 못박으려고, 검증셋으로 직접 에폭을 골랐다면(=부정행위) 얼마였을지도
같이 기록했다. 이건 실제 채택에 쓰지 않았고, 판정을 살려주는 쪽으로 최대한 유리하게 준 상한이다.

```

정칙화를 300배 키운 변형(wd 3e-2)도 채택 val R2 0.0216 로 같은 자리다.

## 판정

사전에 고정한 기준:
```
검증 R2 >= 0.3 이고 PSNR 이득 >= +0.4 dB   -> 예측 가능
검증 R2 <  0.1 이고 PSNR 이득 <  +0.15 dB   -> 예측 불가
그 사이                                        -> 애매
```

실측:
```
검증 R2 (CNN, centered, 16px)                     0.0191
적용 PSNR                                         25.789 dB
전역이득 오라클 대비                                     +0.010 dB
  (이중선형·32px 포함 최선)                             +0.012 dB
국소이득 오라클 상한 대비 회수율                                1.0 %
씬셔플 대조군 R2                                     -0.0034
스칼라 3특징 대조군 R2                                  0.0094
정칙화 강화 변형 R2                                    0.0216
부정행위 상한(검증셋으로 에폭 선택) R2                         0.0365
변형 전부 통틀어 최선 dB                                 +0.016 dB
```

판정: 예측 불가

읽는 법.
- 두 기준 다 '예측 불가' 쪽이다. R2 는 문턱 0.1 의 19%, dB 는 문턱 +0.15 의 11% 다. 경계 근처가 아니라 한 자릿수 배 차이로 미달이다.
- 신호가 0 은 아니다. 씬셔플 대조군(-0.0034)과 스칼라 3특징(0.0094)보다는 위다. 공간 맥락을 보면 스칼라보다 두 배쯤 더 본다. 다만 그 두 배가 0.009 에서 0.019 로 가는 두 배라 실익이 없다.
- 오라클 상한이 +1.187 dB 인데 회수한 게 1.4% 다(변형 전부 통틀어 최선 기준). 국소 이득장은 크고 실재하지만(DIAG_SID_LOWFREQ 2~3번), 그게 어디서 얼마나 틀리는지는 입력 영상에도 모델 출력 영상에도 안 적혀 있다.
- 노출이 짧을수록(0.033s/0.04s) R2 가 조금 더 크고 0.1s 는 0 근처다. 이득장의 예측 가능한 몫이
  극암 쪽에 몰려 있다는 힌트지만, 그 쪽도 dB 로는 +0.02~0.04 라 방법 논문을 세울 크기가 아니다.
- 이 결론은 '단일 영상에서 이 목표 변수를 회귀로 예측' 이라는 설정에 대한 것이다.
  다른 관측(노출 메타데이터, 여러 장, 센서 보정 정보)을 쓰는 설정까지 배제하지는 않는다.

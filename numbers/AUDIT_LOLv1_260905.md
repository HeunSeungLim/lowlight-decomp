# 재현 감사 — CIDNet 공식 가중치 / LOLv1 (260905)

목적: 우리가 뭘 얹기 전에, 저자가 배포한 가중치로 저자가 보고한 수치가 그대로 나오는지 확인한다.
재현이 안 되면 그 위에 쌓는 모든 비교가 무의미하다.

## 방법

- 가중치: Hugging Face 의 저자 배포본 Fediory/HVI-CIDNet-LOLv1-woperc, -wperc.
- 추론: 저자 코드의 망 정의와 평가 설정을 그대로 쓴다(LOL 이므로 model.trans.gated=True,
  크기변경 없이 ToTensor). 저자 수치를 재현하는 게 목적이므로 여기서는 저자 코드를 따른다.
- 채점: 저자 코드를 쓰지 않는다. depth 프로젝트의 audit_port_check.py 관례대로
  PSNR/SSIM 을 numpy 로 독립 재구현했다(자체 가우시안 커널, 자체 분리형 valid 합성곱,
  cv2 와 scipy 미사용). 대조용으로 저자의 cv2 기반 식과 scikit-image 도 같이 돌린다.
- 8비트 변환 규칙도 같이 잰다. 저자 코드는 torchvision ToPILImage 로 저장하는데
  이것은 mul(255).byte() 즉 버림이다. 반올림이 또 하나의 선택지이고 둘은 화소당 최대 1/255 다르다.

## 세 구현의 SSIM 대조

같은 저장 PNG 에 대해:

    독립 재구현      0.870263 (wo_perc) / 0.857396 (w_perc)
    저자 cv2 식      차이 -1.33e-15 / 0.00e+00
    scikit-image     차이 +1.11e-16 / +1.33e-15

세 구현이 부동소수 오차 수준에서 일치한다. SSIM 계산 자체에는 이견이 없다.

## 설명되지 않은 한 칸

wo_perc 의 GT평균 PSNR 만 우리가 +0.060 dB 높다. 나머지 일곱 칸이 0.003 이내인 것과 대비된다.
GT평균 보정 방식 차이를 의심해서 두 가지로 나눠 재봤다.

    저자식 (cv2 RGB2GRAY, uint8 로 반올림 후 평균)   PSNR 28.1999
    독립식 (float 휘도 가중, 양자화 없음)             PSNR 28.2008
    두 방식의 배율 차이 최대 2.19e-04

즉 보정 방식 차이로 설명되는 건 0.001 dB 뿐이고 나머지 0.059 dB 는 설명되지 않는다.
차이가 우리에게 유리한 방향이므로 우리 쪽 유리한 실수는 아니다.
가능한 원인은 저자 표의 해당 칸이 다른 학습 회차 산출물이거나, 배포 가중치와 표 작성 시점이
다른 경우다. 확인 수단이 없으므로 여기서는 미해결로 남긴다.
논문에서 이 수치를 인용할 때는 저자 보고값을 쓰고, 우리 재측정값은 각주로 병기한다.

## 부수 확인 — 8비트 변환 규칙이 공짜로 주는 이득

    가중치     버림(저자 방식)   반올림    차이
    wo_perc   23.4984          23.6087   +0.1103
    w_perc    23.8083          23.8398   +0.0315

저장 PNG 는 float 출력의 버림과 화소 단위로 완전히 일치했다(최대 차이 0 단계).
즉 저자 파이프라인은 버림이 맞다. 반올림으로 바꾸기만 해도 PSNR 이 0.03~0.11 dB 오른다.
이 분야가 0.1 dB 단위로 우열을 다투므로, 우리 논문에서는 어떤 규칙을 썼는지 명시하고
비교 대상과 같은 규칙으로 맞춘다. 반올림으로 얻은 이득을 방법의 이득으로 보고하지 않는다.

## 재현 방법

## 비교 불일치 세 겹 (논문에서 반드시 통제할 것)

1. GT평균 보정 여부.
   Retinexformer README 는 이 설정을 권하지 않는다고 명시한다. GT 를 써서 출력을
   좋게 만드는 설정이기 때문이다. 반면 CIDNet 대표 표의 LOLv1 28.1405 는 GT평균 적용값이다.
   같은 표에서 27.18 과 28.14 를 나란히 두면 서로 다른 설정을 비교하는 것이 된다.

2. 8비트 변환 규칙.
   Retinexformer 는 반올림 쪽이 보고값과 맞는다(25.1523 대 버림 25.0705).
   CIDNet 은 저장 PNG 가 버림과 화소 단위로 일치한다(최대 차이 0 단계).
   두 파이프라인의 규칙이 다르고 그 차이가 LOLv1 에서 0.08 dB, CIDNet wo_perc 에서 0.11 dB 다.

3. 데이터 변종.
   SID 는 두 저자의 화소 규약이 아예 다르다. SID_DATA_NOTE.md 참조.

## 우리 논문의 측정 규약 (선언하고 지킬 것)

- 비교표의 모든 수치는 우리가 같은 데이터, 같은 8비트 규칙, 같은 GT평균 설정으로
  직접 돌려서 만든다. 저자 보고값을 그대로 옮기지 않는다.
- 8비트는 반올림으로 통일하고 본문에 명시한다.
- 주 표는 GT평균 미적용으로 낸다. GT평균 값을 같이 싣더라도 별도 열로 분리하고
  그 설정이 GT 를 사용한다는 것을 캡션에 적는다.
- 저자 보고값과 우리 재측정값이 다르면 둘 다 적고 차이를 설명한다.

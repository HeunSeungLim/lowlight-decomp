# LOLv1 eval15 — SID 진단의 다른 구조·다른 벤치마크 재현

- 대상: LOLv1 eval15 전량 15장 (400x600). 표본이 아니라 전량이지만 15장뿐이라 산포가 크다.
  이 문서의 모든 평균에는 장별 표준편차(sd, n=15, ddof=1)를 같이 적는다.
- 모델 3종. 전부 저자 공개 가중치, 우리 재현 파이프라인과 동일 규약(추론만, 학습 없음).
    CIDNet (woperc) : repro_infer.py --gated lol, HVI-CIDNet-LOLv1-woperc
    CIDNet (wperc)  : 같은 코드, -wperc 가중치
    Retinexformer   : repro_lolv1_retinexformer.py, LOL_v1.pth
- 정의는 전부 SID 진단 코드에서 import 해서 그대로 썼다. 새로 정의한 것은 없다:
    성분 분해   diag_sid_failure.decompose / p2
    방사 11구간 diag_sid_spectrum.RAD_EDGES, 저역통과 sigma 격자 SIGMAS, gaussian_blur

    사다리      diag_sid_lowfreq.BLOCKS/block_fit, 저주파 대역수 LP_NBAND=2
- 채점은 repro_measure 의 독립 구현(psnr_indep/ssim_indep)만 사용. 전부 실측값.

## 3. 대역 라벨 — 입력에 정보가 있는가, 모델이 다 썼는가

입력을 두 갈래로 잰다(둘 다 공간 이웃을 쓰지 않으므로 위치정보를 새로 만들지 못한다):
    scalar : 저조도 입력 x 장별 최적 스칼라 이득 = '밝기만 맞춘 입력'
    pw     : 같은 입력값 화소를 GT 평균으로 보내는 장별 오라클 포인트와이즈 사상
rho 는 스케일 불변이라 스칼라 이득은 rho 를 바꾸지 못한다(밝기 정합은 PSNR 표시용).

★ 못 하는 것: SID 에서는 같은 씬을 여러 번 찍은 short 프레임이 있어서 잡음 파워를 실측하고
  rho_dn = rho/sqrt(1-N/P) 로 '정보 천장' 을 만들 수 있었다. LOLv1 eval15 에는 같은 씬
  반복 촬영이 없다. 잡음 파워를 측정할 자료가 없으므로 잡음보정 천장 기준과 k장 평균 기준은
  LOLv1 에서 계산할 수 없다. 아래 판정은 diag_sid_identifiability 4-(c) 의 '원 입력 기준'
  (잡음 보정 안 한 rho_in(pw) k=1 대 rho_out) 이며, SID 문서의 같은 기준 표와 직접 비교된다.

판정 규칙(고정 임계, import 한 verdict 그대로): 불가 rho_in < 0.2, 회복가능 rho_in - rho_out > 0.05, 그 밖 소진

## 5. 국소 보정 사다리

블록마다 최소제곱 스칼라를 골라 GT 에 맞춘다(계수는 채널 공통, 전역이득 오라클과 같은 단위).
  gain : a_blk * y          (전역 1x1 = 전역이득 오라클)
  off  : p + b_blk          (전역이득 보정 출력에 국소 오프셋만)
  aff  : a_blk * y + b_blk  (블록마다 2 자유도)
대조군은 같은 절차·같은 블록수로 목표만 바꾼 것이다:
  white : 목표 = p - (같은 분산 백색잡음)  -> 구조 없는 잔차. 이게 자유도 대조군이고 이 값을 뺀다.
  perm  : 목표 = p - (다른 장의 잔차, 채널별 분산 정합) -> 구조는 그대로, 이 장과의 정합만 깬 것. 안 뺀다.

★ 블록 개수가 SID 와 다르다. LOLv1 은 400x600, SID 는 512x960 이라 같은 블록 크기에서
  블록 수가 대략 절반이다(아래 표의 '블록수' 열, 괄호 안이 SID 값). 화소당 자유도는 비슷하지만
  경계 블록 비율이 달라 완전히 같은 조건은 아니다. 그래서 white 대조군을 반드시 같이 낸다.

GT평균 보정과 전역이득 오라클은 서로 다른 스칼라를 쓴다. 클리핑 없는 MSE 에서는 최소제곱
전역이득이 항상 이기고(15/15 장에서 확인), 클리핑+8bit 후 장별 dB 평균에서는 GT평균이 4/15
장에서 앞선다. 두 값이 0.1 dB 안에서 만나는 건 그 때문이고 모순이 아니다.

### 항목별로 풀어서

- (1) 성분 분해는 불일치다. 이 문서에서 가장 중요한 결과다. SID 에서는 전역이득(밝기) 이 오차의
  27.0% 였고 전역+채널 오라클을 다 써도 +2.02 dB 가 상한이었다. LOLv1 에서는 CIDNet 두 벌이
  각각 75.7% / 74.9% 로 밝기가 오차의 지배항이고, 전역이득 하나만 오라클로 맞춰도
  +4.28 dB / +3.62 dB 가 들어온다.
  Retinexformer 는 그 중간이다(41.4%, +1.95 dB).
  즉 'SID 의 실패는 밝기 문제가 아니다' 는 결론은 LOLv1 로 그대로 옮겨가지 않는다.
  같은 벤치마크 안에서도 구조에 따라 갈린다(CIDNet 75% 대 Retinexformer 41%).
  다만 이건 CIDNet 의 결함이라기보다 평가 규약 문제에 가깝다 - CIDNet 저자 표는 GT평균 설정을
  쓰고, 그 설정이 여기 전역이득 오라클과 사실상 같은 일을 한다(0번 대조의 GT평균 28.20 대
  전역이득 오라클 28.13).
  채널이득(색편향) 몫은 SID 8.76% 대 LOLv1 1.1~4.1% 로 한자리수라는 점만 같고 크기는 2~8배 작다.
- (2) 대역별 파워비/rho 는 방향이 같다. 저주파는 거의 완벽히 맞고 고주파로 갈수록 출력 파워가
  GT 밑으로 내려가며 rho 가 단조 감소한다. 크기는 LOLv1 이 훨씬 덜 심하다
  (코너 대역 rho: SID 0.488 대 LOLv1 0.604~0.581).
  LOLv1 이 SID 만큼 어둡지 않으니 예상되는 방향이다.
- (3) 원 입력 기준 대역 라벨은 세 모델 전부 11대역 소진으로 SID 와 같다. '회복가능' 대역이
  하나도 없다는 것도 같다. 다만 SID 에서 쓴 잡음보정 천장 기준과 k장 평균 기준은 LOLv1 에서
  자료가 없어 못 했으므로, 이 일치는 SID 의 세 기준 중 가장 약한 기준에서의 일치다.
- (4) 저역통과 대조는 방향이 같고 크기가 작다. SID 는 blur_0.6(GT) 가 모델출력보다 +0.882 dB
  가까웠고, LOLv1 은 +0.50~+0.61 dB 다. 최적 sigma 는 0.5~0.6 으로 사실상 같다.
  '모델 출력이 GT 자신보다 저역통과된 GT 에 더 가깝다' 는 진술은 두 벤치마크·세 모델 전부에서 성립한다.
- (5) 국소 보정 사다리는 일치한다. 자유도 대조군(white)은 두 벤치마크 모두 16화소 블록에서
  0.006 dB 로 무시할 수준이고, gain 열은 LOLv1 이 더 크다
  (gain blk16 보정후 SID +1.194 대 LOLv1 +2.29/+2.11/+1.17; aff 는 SID +1.819 대 LOLv1 +2.34/+2.27/+1.95).
  블록 수가 SID 의 절반인데도(400x600 대 512x960) 이득이 더 크다는 게 중요하다 - 자유도가
  아니라 실제 공간적으로 변하는 저주파 오차가 있다는 뜻이다.
- (6) 저주파 성분 몫도 일치한다. SID 64.35% 대 LOLv1 67~70%(RGB, E가중). 최저 방사대역이
  오차의 과반을 갖는 것도 같다(SID 54.73% 대 LOLv1 61~64%).

### 한 줄 요약

- 옮겨가는 것: 오차의 저주파 지배, 공간적으로 변하는 국소 보정 여지, 고주파 감쇠와 rho 단조감소,
  최적 저역통과 sigma 0.5~0.6, 원 입력 기준 대역 라벨(전부 소진), 자유도 대조군이 무의미하다는 점.
- 안 옮겨가는 것: 성분 분해의 비율. LOLv1 에서는 밝기(전역이득)가 CIDNet 계열의 지배 오차이고
  출력단 이득 보정만으로 +3.6~4.5 dB 가 들어온다. SID 에서 나온 '톤 정합류로는 못 메운다'
  는 진술은 벤치마크·모델 의존적이다.
- 15장 기준이라 위 수치의 장별 sd 가 크다(모델 PSNR sd 2.9~5.6 dB). 방향성 결론에는 견디지만
  비율 값을 소수점 아래까지 인용하면 안 된다.

# SID 극암 저조도 — Retinexformer 실패지점 진단

- 대상: SID test split 전량 598장 / 50씬 (표본 아님)
- 모델: Retinexformer 저자 SID.pth, 우리 재현 파이프라인(repro_sid_retinexformer.py)과 동일 규약
- 앵커: 무보정 PSNR 24.438 / SSIM 0.6800 (재현값 24.438 / 0.680 과 일치)
- 채점은 repro_measure 의 독립 구현(psnr_indep/ssim_indep)만 사용. 전부 실측값.

## 1. 오차의 구성 분해 (전량 598장)

정의: 출력 p, GT g. (a) 스칼라 하나 a*p 로 없어지는 몫, (b) 채널별 a_c*p_c 로
추가로 없어지는 몫(색 편향), (c) 나머지. 계수는 장별 최소제곱해.

```
성분                        에너지가중 몫    장별평균 몫
-------------------------------------------------------
(a) 전역 이득(밝기)            27.03 %      22.06 %
(b) 채널 이득(색 편향)          8.76 %       7.63 %
(c) 나머지(구조/디테일)        64.21 %      70.30 %
[참고] 채널 offset 추가분        6.79 %          -
```

성분을 완벽히 제거했을 때 도달하는 PSNR (장별 최적 계수 = 오라클):

```
보정 단계                              PSNR      SSIM     이득
--------------------------------------------------------------
무보정 (모델 출력 그대로)              24.438   0.6800      -
(a) 제거: 전역 이득 오라클             25.755   0.6857   +1.317 dB
(a)+(b) 제거: 채널 이득 오라클         26.455   0.6882   +2.016 dB
[참고] 채널 affine(이득+흑레벨)        27.011      -      +2.573 dB
```
(PSNR 열은 클리핑 없는 최소제곱 잔차 기준. 실제로 [0,1] 클리핑+8bit 반올림해서 다시 재면 전역 25.775 / 채널 26.484 로 거의 같다.)

장별 최적 전역 이득 평균 1.0004, 채널 이득 평균 R/G/B = 1.0066 / 0.9941 / 0.9865

## 3. 입력 밝기별 화소 단위 분해

구간 기준은 GT 가 아니라 입력(short) 의 국소 휘도(0.299R+0.587G+0.114B, 0-255).
절대오차는 화소×채널 단위, 중앙값/90분위는 전량 히스토그램에서 정확히 계산.

```
입력휘도  화소비율  평균입력  평균GT휘도 | |err|중앙값 |err|평균 |err|p90 | 오차E몫  E몫/화소몫 | 상대오차
--------------------------------------------------------------------------------------------------------
     0-2    15.16%      0.68      36.08 |          7     10.42       24 |   11.94%       0.79 |    28.9%
     2-5    11.00%      3.39      48.72 |          8     11.46       27 |    9.48%       0.86 |    23.5%
    5-10    13.30%      7.40      60.48 |          8     11.73       26 |   11.52%       0.87 |    19.4%
   10-20    19.86%     14.66      75.06 |          9     12.61       28 |   18.85%       0.95 |    16.8%
   20-40    20.70%     28.60      97.85 |         10     13.39       29 |   21.74%       1.05 |    13.7%
   40-80    13.19%     54.76     134.74 |         10     13.56       29 |   14.21%       1.08 |    10.1%
```

상대오차 = |err|평균 / 평균GT휘도. 오차E몫/화소몫 이 1보다 크면 그 구간이 오차를 과대 분담한다.

## 5. 재현 가능성의 상한 — 같은 씬 안에서 출력이 얼마나 갈리는가

같은 씬의 서로 다른 short 입력은 같은 GT 를 공유한다. 그 입력들에 대한 모델 출력끼리
PSNR 을 재면, 모델이 입력 잡음을 얼마나 '내용'으로 옮기는지 보인다.
입력끼리의 PSNR 은 대조군(입력이 원래 얼마나 다른가).

```
쌍 종류                    쌍 수   출력간 PSNR   입력간 PSNR   출력-입력
--------------------------------------------------------------------------
같은 씬·같은 노출 0.033s      14       28.234        14.311     +13.924
같은 씬·같은 노출 0.04s      741       28.860        14.391     +14.468
같은 씬·같은 노출 0.1s      1649       32.153        25.054      +7.099
같은 씬·다른 노출            986       27.145        16.021     +11.125
전체                        3390       29.960        20.052      +9.909
```

입력 잡음만 다른 두 입력에 대한 출력 차이를 조건부 평균 주위의 독립·등분산 편차로 보면,
출력분산 = (쌍 MSE)/2 이고 이것이 모델 전체 MSE 에서 차지하는 몫을 추정할 수 있다.
(독립·등분산 가정에 의존하는 추정치다. 실측은 쌍 MSE 와 모델 MSE 뿐이다.)

```
노출     쌍MSE/2   모델MSE   잡음기인 몫(추정)
---------------------------------------------
0.033s      61.05    445.92             13.7 %
0.04s       52.30    407.77             12.8 %
0.1s        26.50    280.84              9.4 %
전체          34.65    326.78             10.6 %
```

참고: 모델이 GT 에 대해 내는 PSNR 은 24.438 dB 다. 같은 씬 같은 노출 입력 두 장에 대한 출력끼리도 28.234~32.153 dB 밖에 안 맞는다.

## 측정이 가리키는 것

- 극암 실패는 밝기/색 편향 문제가 아니다. 장별 오라클로 전역 이득과 채널 이득을 완벽히 맞춰도 24.44 -> 26.45 dB, +2.02 dB 가 상한이고, 가장 어두운 0.033s 에서는 그 상한이 +1.52 dB 로 더 작다. 출력단 캘리브레이션/톤 정합류로는 남은 격차를 못 메운다.
- 오차의 64%(0.033s 는 73%)는 이득으로 안 없어지는 구조 잔차이고, 화소당 절대오차는 입력 휘도 0.7 에서 130 까지 8~10 수준으로 거의 평평하다. 극암 화소가 오차를 지배한다는 통념은 이 데이터에서 성립하지 않는다(0-2 구간은 화소 15.2% 에 오차에너지 11.9%). 다만 상대오차는 극암 28.9% 대 밝은 곳 8.1% 로 3.6배다 - 절대 스케일이 아니라 상대 정확도에서 진다.
- 잡음 실현에만 의존하는 몫은 전체 오차의 11% 로 추정된다(독립·등분산 가정). 잡음 억제나 여러 실현의 평균만으로 얻을 수 있는 이론 상한은 약 0.5 dB 수준이라는 뜻이고, 지배 항이 아니다.
- 학습이 자명한 기준선 위로 버는 몫은 8.7 dB(SSIM 0.19 -> 0.68)로 이미 크다. 장별 GT 를 본 오라클 감마·이득조차 PSNR 15.8 에 그치므로, 전역 톤 곡선 형태의 사전지식은 소진된 상태다.
- 남은 몫은 노출이 짧아질수록 커지는 구조 잔차 하나에 몰려 있다(나머지 성분 몫 0.1s 61% -> 0.033s 73%). 숫자가 요구하는 것은 밝기 보정이나 디노이즈 강화가 아니라, 입력 신호대잡음 수준에 조건화되어 모든 밝기 구간에서 상대 정확도를 올리는 복원이다. 이 이상은 이 측정만으로 특정되지 않는다.

# SID 극암 저조도 — 여러 장을 모으면 실제로 얼마나 가져오는가

- 대상: SID test split 전량 598장 / 50씬 (표본 아님). 노출별 0.033s 28장/14그룹, 0.04s 180장/29그룹, 0.1s 390장/50그룹
- 모델: Retinexformer 저자 SID.pth. 학습 없음. 가중치 그대로, 입력만 바꿨다.
- 모델 forward 총 1353회. 로더·대역정의·이득정합·8bit 반올림 규약은 diag_sid_spectrum.py / diag_sid_failure.py 에서 그대로 import 했다.
- 채점은 repro_measure 의 독립 구현(psnr_indep/ssim_indep)만 사용. 전부 실측값.

조합 선택 규약 (고정, 사후조정 없음):
  그룹(같은 씬·같은 노출) 안 프레임을 파일명 정렬 순으로 놓고 앞에서부터 겹치지 않는
  연속 k 장 블록을 floor(n/k) 개 만든다. 남는 프레임은 버린다. 가능한 모든 조합을
  평균내지 않는다 - 조합 수가 k 마다 달라져 표본 가중이 틀어지기 때문이다.
  평균은 npy(이미 노출비로 증폭된 uint8) 를 [0,1] 로 바꾼 뒤 산술평균이다.

코호트 세 가지. 이걸 안 나누면 k 마다 평가 대상이 달라져 결과가 무효다:
  all   : 모든 그룹의 모든 블록. k 가 커지면 짧은 그룹이 빠져 씬 구성이 바뀐다.
  fix   : n >= KFIX 인 그룹만 (씬 구성 고정). 블록 수는 k 마다 다르다.
  match : n >= KFIX 이고 k 가 KFIX 를 나누는 경우, 앞 KFIX 장만 써서 만든 블록.
          k 를 바꿔도 정확히 같은 씬·같은 프레임 집합을 쓴다. 이게 정본 대조다.
  KFIX = 0.033s:2, 0.04s:8, 0.1s:8 (그 노출 그룹의 최대 프레임 수가 허용하는 2의 거듭제곱)

### (2-a) 총 노출이 같은 단일/소수 프레임과의 대조

k 장 평균은 입력이 k 배 더 많은 광자를 쓴다. 그러니 '같은 총 노출을 한 번에 찍은 것'
과 비교해야 공정하다. 이 데이터셋의 short 노출은 0.033 / 0.04 / 0.1s 세 가지고,
총 노출 t1*k1 == t2*k2 를 만족하는 (노출,k) 쌍을 전수 열거했다.
가능 여부는 '그 씬이 두 쪽 프레임 수를 다 갖고 있는가'로 판정한다.

## 측정이 가리키는 것

- 여러 장은 값을 가져오지만 넣는 방법이 부호를 바꾼다. 같은 씬·같은 프레임 집합에서 0.033s 22.491 -> k=2 입력평균 20.080(-2.411) / 출력평균 22.811(+0.320) / 0.04s 22.955 -> k=8 입력평균 20.875(-2.080) / 출력평균 23.519(+0.564) / 0.1s 25.351 -> k=8 입력평균 20.779(-4.572) / 출력평균 26.023(+0.672) dB 다. k 장을 먼저 평균해 넣으면 크게 나빠지고, 각각 넣어 출력을 평균하면 k 에 대해 단조로 좋아진다(최소 증분 +0.086 dB).
- 입력평균이 무너지는 곳은 구조가 아니라 밝기다. 0.1s k=8 입력평균에서 대역 상관은 거의 전 대역에서 오르고(코너 0.50-0.71 rho_out 0.579 -> 0.724), 고주파 잔차 에너지도 84% 로 준다. 그런데 전역이득 오차 에너지가 458% 로 뛴다. 모델이 입력 잡음 수준을 밝기 단서로 쓰고 있고 평균해서 깨끗해진 입력이 학습 분포 밖이라는 해석과 맞지만, 이 측정은 그 인과를 분리하지 않았다(가설). 밝기 오차는 국소 보정으로도 다 안 지워진다 - 입력평균 k=8 에 오라클 국소affine16 을 먹여도 28.338 로, 같은 오라클을 k=1 에 먹인 28.980 보다 낮다.
- 총 노출을 맞추면 여러 장이 진다. 총 노출이 정확히 같은 유일한 조합인 0.04s 5장(0.2s) 대 0.1s 2장(0.2s)에서 출력평균끼리 23.444 대 25.146 dB 로 1.702 dB 뒤진다. 같은 광자를 더 잘게 쪼개 읽으면 손해라는 뜻이고, 장마다 더해지는 읽기 잡음과 일관되지만 이 측정으로 원인을 분리하지는 않았다(가설). 0.04s x2 대 0.1s x1 은 총 노출이 20% 적은 쪽이 A 라 불리하지만 방향은 같다(-2.243 dB).
- 지배 성분인 저주파는 여러 장으로 거의 안 준다. 출력평균 기준 D 에너지몫은 0.033s 65.54% -> 63.52%(에너지 89%) / 0.04s 62.24% -> 58.43%(에너지 80%) / 0.1s 66.19% -> 68.76%(에너지 91%) 이고, 0.1s 는 몫이 오히려 늘었다. 입력평균에서는 저주파 에너지가 235% 로 폭증한다. 프레임 평균이 지우는 것은 고주파 잡음이지 밝기장 오차가 아니다.
- 크기 감각: 같은 코호트(36씬)에서 오라클 사다리는 k=1 무보정 25.351 위로 전역이득 26.687, 국소이득16 27.853, 국소affine16 28.980 다. 8장 출력평균이 실제로 가져온 것은 26.023(+0.672 dB)로, 국소affine16 여유 +3.629 dB 의 19% 다. '여러 장에 여유가 있다'는 진술은 성립하지만 그 몫은 작고, 큰 여유는 여전히 밝기장에 있다.

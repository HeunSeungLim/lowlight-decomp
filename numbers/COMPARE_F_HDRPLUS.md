# 비교 실험 F — HDR+ 계열 잡음분산 기반 주파수 병합 vs 단일/균등평균/출력평균

- 대상: SID test split 전량 598장 / 50씬. 노출별 0.033s 28장/14그룹, 0.04s 180장/29그룹, 0.1s 390장/50그룹
- 모델: Retinexformer 저자 SID.pth. 학습 없음, 추론만. GPU 0.
- 병합: code/merge_hdrplus.py 의 merge(frames, c, tile=16, sigma) 를 그대로 호출. sigma 는 블록 프레임에서 estimate_sigma 로 추정(모든 c 에 같은 값). 기본 c=8.
- 병합 출력은 [0,1] 밖으로 약간 나가므로 클리핑 후 모델에 넣었다(아래 5절에 비율).
- 모델 forward 4044회, 병합 450블록 x 4개 c.
- 채점: repro_measure 의 psnr_indep / ssim_indep (독립 구현), 8bit 반올림.
- 추론: cudnn TF32 끔 + deterministic (앵커 대조 절 참조).
- 그룹·블록·코호트 규약은 multiframe_gain.py 와 동일(재구현, --audit-groups 로 대조).

네 팔:
  A  단일 프레임      f(x_1)                x_1 = 블록의 첫 장
  B  균등 평균 입력    f(mean(x_1..x_k))
  C  출력 평균        mean_i f(x_i)         forward k 회
  F  HDR+ 병합 입력    f(merge(x_1..x_k; c)) 기준 프레임 = x_1

코호트:
  all   : 모든 그룹의 모든 블록 (k 마다 씬 구성이 바뀐다)
  match : n >= KFIX 인 그룹의 앞 KFIX 장만, k 가 KFIX 의 약수. k 를 바꿔도 같은 씬·같은 프레임. 정본.
  KFIX = 0.033s:2, 0.04s:8, 0.1s:8
  같은 k 안에서는 네 팔이 정확히 같은 블록(같은 씬, 같은 프레임 부분집합)에서 채점됐다.

## 3. F 와 B 의 차이를 방사 주파수 대역별로

대역 정의는 diag_sid_spectrum.RAD_EDGES (주기/화소 단위 방사 주파수, 0.05 폭 10개 + 코너 1개). 휘도(0-255), 장 전체 FFT, Parseval 로 대역 합 = 평균제곱.
비율은 블록 합(에너지 가중). 읽는 법:
  dFB/rB   : 대역별 [F 출력 - B 출력] 파워 / [B 출력 - GT] 잔차 파워. 두 출력의 차이가 그 대역 오차 대비 얼마나 되는가.
  dAB/rB   : 같은 식으로 [A 단일 - B 평균]. 프레임을 하나만 쓴 것과 평균한 것의 차이 = 스케일 기준.
  dxm/dx1  : 입력 쪽. [병합 입력 - 평균 입력] 파워 / [x_1 - 평균 입력] 파워. 평균이 지운 잡음 대비 병합이 얼마나 벗어났는가.
  share    : dFB 파워가 11개 대역에 어떻게 분포하는가 (합 100%).

## 측정이 가리키는 것

- 같은 50씬(0.04s+0.1s, match)에서 F(c=8) 는 B 를 k=2 +0.292 / k=4 +0.670 / k=8 +0.906 dB 이기지만 (블록 68% 에서 F>B), 여전히 A 단일 프레임보다 2.97 dB, C 출력평균보다 3.61 dB 낮다(k=8). 입력 쪽에서 프레임을 모으면 모델이 나빠지는 현상은 표준 병합에서도 그대로다.
- c 는 단조다: match 코호트 7개 (노출,k) 전부에서 F(2) > F(4) > F(8) > F(16) > B (예외 없음). 폭은 k=8 에서 1.09 dB. c 가 작을수록 기준 프레임으로 물러나 A 에 가까워지므로 GT 로 고른 최적 c=2 는 '덜 병합할수록 낫다'는 뜻이지 병합이 좋다는 뜻이 아니다.
- 입력에서 병합과 균등평균의 차이 파워는 평균이 지운 잡음의 4.7~4.8% 뿐이고 대역에 걸쳐 평평하다(0.1s k=8 최저 대역만 45%). 즉 f>0.10 에서 병합은 균등 평균과 사실상 같다.
- 출력에서 F−B 차이 파워의 87% (k=2) ~ 92% (k=8) 가 최저 대역 f<0.05 에 있고, 그 대역에서 F 의 잔차는 B 의 0.78배(k=8; A 는 0.30배), f>=0.10 대역들은 평균 0.972배로 B 와 같다. F 가 B 를 이기는 몫은 전부 저주파에서 기준 프레임 쪽으로 남아 있는 데서 온다.
- 결론: 이 데이터(삼각대 정지, 정렬 없음)에서 HDR+ 계열 병합은 중·고주파에서는 균등 평균과 같고, 저주파에서만 단일 프레임 쪽으로 치우친 '평균과 단일 사이의 보간'이다. F 를 이겨야 한다는 조건은 사실상 A 와 C 를 이겨야 한다는 조건과 같다.

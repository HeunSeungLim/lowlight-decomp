# SID 극암 저조도 — 고주파 정보가 측정에 남아 있는가

- 대상: SID test split 전량 598장 / 50씬 (표본 아님). 노출별 0.033s 28장/14그룹, 0.04s 180장/29그룹, 0.1s 390장/50그룹
- 주파수 구간·로더·이득 정합 규약은 diag_sid_spectrum.py 에서 그대로 import 해서 썼다(같은 11구간).
- 앵커: 모델 무보정 PSNR 24.438 (DIAG_SID_FAILURE 24.438 과 일치)
- 이 문서의 rho 는 전부 방사 주파수 구간별 상관계수(휘도):
    rho_b = sum_{k in b} Re[F_p conj(F_g)] / sqrt( sum_b |F_p|^2 * sum_b |F_g|^2 )
  구간마다 따로 계산하므로 DC·극저주파가 다른 구간을 지배하지 못한다(DC 는 첫 구간 안에서만 작용).
  rho 는 스케일 불변이라 스칼라 이득은 rho 를 바꾸지 못한다. 이득 정합은 파워·PSNR 표시용이다.
- 입력을 네 갈래로 잰다. 넷 다 공간 이웃을 쓰지 않으므로 위치정보를 새로 만들어내지 못한다.
    scalar   : short 입력 x 장별 최적 스칼라 이득 (구조 손 안 댐, 지시받은 기본형)
    pw       : 같은 입력값 화소를 GT 평균으로 보내는 장별 오라클 포인트와이즈 사상
               (톤 곡선 불일치만 제거한다. short->long 관계가 비선형이라 scalar 는 그만큼 rho 를 깎아먹는다)
    -dn      : 각 갈래에서 실측 잡음 파워를 빼 잡음 희석을 지운 값 = 프레임 무한 평균의 극한 추정
    k 평균   : 같은 씬·같은 노출 입력 k 장 평균 (2번). 이쪽은 추정이 아니라 실측이다.

읽는 법. rho 는 상관이라 입력의 잡음이 그대로 rho 를 깎는다. 모델 출력은 잡음이 억제된 추정치라
같은 정보량이어도 rho 가 더 높게 나온다. 그래서 raw 입력 rho 와 모델 rho 를 그냥 비교하면 안 되고,
잡음을 벗겨낸 값(-dn)이 '이 측정이 담고 있는 정보의 천장'이다. 보정식은
  rho_dn = rho / sqrt(1 - N/P),  N = 실측 잡음 파워, P = 입력 대역 파워
이고 합끼리의 연산이라 데이터셋 집계값에 대해 정확하다. 잡음이 GT 와 무상관이므로 분자(교차항)는
건드리지 않는다.
이 보정을 5번에서 검정했다: scalar 갈래는 통과(가법 잡음 모형이 정확하다), pw 갈래는 저주파
네 대역에서 반증됐다 - 실제로 k 장을 평균해 잰 값보다 작게 나온다. 프레임을 모으면 잡음만 주는
게 아니라 포인트와이즈 사상 자체가 정확해지는데 이 보정식은 그 몫을 못 보기 때문이다.
반증 방향이 과소평가 쪽이고 고주파 대역은 반증되지 않았다. 아래 판정 열은 이 천장 추정 기준이고,
가정 없는 실측 판정은 4번 (b) 다.
주의: N/P 가 0.9 를 넘는 칸은 보정 배율이 3배를 넘어 값이 불안정하다(짧은 노출의 고주파가 그렇다).

판정 규칙 (고정 임계, 사후조정 없음). 이 표의 비교 대상은 정보 천장 추정 rho_in(pw-dn) 이다:
  불가     : rho_in(pw-dn) < 0.2           -> 그 대역은 이 측정에 정보가 사실상 없다
  회복가능 : rho_in(pw-dn) - rho_out > 0.05   -> 입력에 있는데 모델이 못 쓰고 있다
  소진     : 그 밖                          -> 모델이 이미 가용 정보를 다 쓰고 있다
오차몫% 은 현재 모델(전역이득 보정 후) 잔차 파워의 대역별 몫이다(합 100).

## 2. 프레임을 k 장 모으면 정보가 늘어나는가 (핵심)

같은 씬·같은 노출 short 입력을 k 장 평균(겹치지 않는 블록)한 뒤 같은 rho 를 다시 잰다.
장면과 노출이 같으니 신호는 그대로고 잡음만 1/k 로 준다. k 가 커질 때 고주파 rho 가 오르면
정보는 측정에 있고 단일 프레임 잡음에 묻힌 것이다. 안 오르면 프레임을 더 모아도 없는 정보다.
코호트 fix = 그 노출에서 k=KFIX 까지 만들 수 있는 그룹만 (k 사이 비교를 같은 씬에서 한다).

*_inf 는 k -> 무한 외삽이다. 가법·독립 잡음 + 스칼라 이득이면
  1/rho_k^2 = A + B/k  (A = k->무한 극한, B 는 잡음 몫)
가 정확히 성립한다. 측정한 k 점들로 이 직선을 최소제곱 적합해 A 에서 rho_inf = 1/sqrt(A) 를 얻었다.
직선성 자체가 검증 대상이다(최대 적합잔차는 5번 산수 대조에 있다). pw 갈래는 사상이 비선형이라
이 직선 관계가 보장되지 않으므로 pw_inf 는 경험적 외삽으로만 읽는다.

### 잡음 보정값이 k 에 무관한가 (보정식의 자기 정합)

rho_dn = rho_k / sqrt(1 - N_k/P_k) 는 k 를 뭘로 잡든 같은 값이 나와야 한다(같은 극한을 잰다).
k 를 바꿔 가며 같은 fix 코호트에서 계산했다. 코너 대역(0.50-0.71) 값이고, 전 대역 최대 편차는
맨 오른쪽이다.

## 3. 상한 환산 — rho 를 PSNR 로

유도. 한 구간 b 에서 입력의 주파수 계수 벡터를 P, GT 를 G 라 하고 실수 스칼라 s 로 진폭만 맞춘다.
  J(s) = ||sP - G||^2 = s^2 ||P||^2 - 2 s Re<P,G> + ||G||^2
  dJ/ds = 0  ->  s* = Re<P,G> / ||P||^2
  J(s*) = ||G||^2 - (Re<P,G>)^2/||P||^2 = ||G||^2 (1 - rho_b^2),
          rho_b = Re<P,G> / (||P|| ||G||)
파스발로 화소당 평균제곱오차는 구간 합이 된다(C=3 채널):
  MSE_min = (1/C) sum_c sum_b P_gt[b,c] (1 - rho[b,c]^2),  PSNR = 10 log10(255^2 / MSE_min)

가정:
  (i)   구간 독립 - 구간마다 실수 이득 하나를 서로 무관하게 고른다.
  (ii)  위상 최적 사용 - 주어진 신호의 위상을 그대로 쓰는 것이 이 클래스의 최적이라는 뜻이고,
        위상을 GT 쪽으로 고칠 수 있다는 뜻이 아니다.
  (iii) 이득은 장별·채널별·구간별 오라클(GT 를 보고 고름) - 그래서 상한이다.
  (iv)  클리핑·8bit 반올림 없음. 클리핑은 [0,1] 볼록집합 사영이라 실제로는 오차를 못 늘린다.
따라서 이 값은 '주어진 신호의 대역 진폭만 재조정하는 추정기' 클래스의 최적값이다.
비선형 추정기는 이 클래스 밖이라 이 수를 넘을 수 있다. 실제로 모델이 scalar 입력의 값을 넘는다.

## 측정이 가리키는 것

- 고주파 정보가 측정에 남아 있긴 하다. 코너 대역(0.50-0.71) 단일 프레임 rho 는 pw 0.218 로 낮지만 그 대역 입력 파워의 90% 가 잡음이고, 프레임을 모으면 실제로 오른다(0.1s 같은 씬 k=1 0.328 -> k=8 0.542). 잡음이 독립이라는 것도 확인했다 - 프레임 차이 파워는 시간 간격과 무관하고 k 평균에서 정확히 1/k 로 준다(편차 1.7% 이내).
- 그런데 단일 프레임만 놓고 보면 모델이 이미 다 쓰고 있다. 잡음 보정 없이 비교하면 11개 대역 전부에서 모델 rho 가 입력 rho 이상이고, 8장을 평균해서 잰 값과 비교해도 회복가능으로 찍히는 대역이 하나도 없다(0.1s 코너 k=8 0.542 vs 모델 0.579). 판정은 (b) 소진이다.
- 짧은 노출의 고주파는 판정이 (c) 불가다. 0.033s 는 2장을 평균해도 코너 rho 0.036, 0.25 이상 여섯 대역이 전부 0.2 아래다(오차의 20.9%). 0.04s 도 0.35 이상 네 대역이 그렇다(16.2%). 이 대역들은 어떤 방법으로도 못 살린다 - 진폭이 아니라 위치정보 자체가 측정에 없다.
- 여지가 남는 곳은 '여러 장'뿐이다. 잡음을 벗겨낸 천장 추정은 0.1s 코너에서 0.807 로 모델 0.579 를 웃돌고, 전체로는 오차의 20.4% 에 해당하는 고주파 6개 대역이 여기 걸린다. 다만 이 추정은 저주파에서 실측 k 평균보다 작게 나와 반증됐다(5번). 고주파 칸은 반증되지 않았고 반증 방향도 과소평가 쪽이라 이 몫은 보수적인 값이다.
- 오차의 절반 이상(54.7%)은 여전히 최저주파 대역(0.00-0.05)에 있고 거기는 어느 기준으로도 소진이다. 고주파를 되살리는 것으로 얻을 수 있는 몫의 상한이 20% 대라는 뜻이다.
